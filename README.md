# Андрей Петров — Логика и практика

Персональный профессиональный лендинг Андрея Петрова о проектах на стыке анализа, концепций, культуры, цифровых продуктов и практической реализации.

[Опубликованный сайт](https://petrovmandrey.github.io/portfolio/)

## Проекты

1. АРК — авторская проектная платформа.
2. Грантмастер — цифровой помощник для проектных инициатив.
3. SVETLO («Светло») — интернет-магазин интерьерного освещения.
4. Индустриальный музей Красногвардейского района — концепция цифрового музея.
5. Агент.Метрика — аналитика цифровых фондов.
6. Студия рассылок — дайджесты и публикации для культурных организаций.
7. Реестр ЗАЛов — приложение для работы с реестром электронных читальных залов.
8. 8 филиалов — концептуальный сервис управления филиальной сетью.
9. Рабочий компас — навигатор внутри организации.
10. Мобильные приложения — «Сова», «Форум», «Полка», «Заметка».

## Технологии и локальный запуск

HTML / CSS / JavaScript, без фреймворков и сторонних runtime-зависимостей.

Откройте `index.html` в современном браузере с включённым JavaScript. Сайт работает через `file://`; установка зависимостей и локальный сервер не требуются. Сохраняйте структуру папок репозитория.

Архитектура, сборка, проверки и правила разработки описаны в [DEVELOPMENT.md](DEVELOPMENT.md).
